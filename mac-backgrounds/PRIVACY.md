# Living Desktop — Privacy Policy

**Effective date: October 21, 2026**

Living Desktop is a locally running macOS decoration app. It does **not** collect, track, sell, or transmit personal data. It does not include advertising, analytics, accounts, a remote backend, or network requests.

### Information used on your device

- **Window geometry:** The app reads the positions, sizes and identifiers of currently visible windows through public macOS APIs to place visual effects. It does not read window titles or capture window contents, screenshots, keyboard input, or clipboard data. Geometry is held in memory while effects are running.
- **Microphone (optional):** When you explicitly enable sound reaction for the Music Visualizer, macOS may request microphone permission. Audio is analyzed only in memory to calculate a momentary sound level. Audio recordings are never created, stored or sent anywhere. You can disable this feature at any time or revoke permission in macOS System Settings.
- **Wallpaper image (optional):** When you choose a new wallpaper in the macOS file picker, the app accesses only that user-selected picture to ask macOS to set it as the desktop image. The filename is shown in the settings panel for the current app session. The picture is never uploaded, copied to a server, or read automatically on startup.
- **Preferences:** The selected effect, intensity, window/desktop options, frame-rate preference, wallpaper toggle, favorites, and onboarding setting are stored on your Mac through UserDefaults. These settings remain on the device.
- **Start at login (optional):** If you explicitly enable Launch at Login, macOS manages the registration. You can disable it in the app or in System Settings.

### Retention and deletion

Window geometry and sound levels exist only in memory while the feature is active. Settings remain in your macOS user profile until you reset or remove the app's preference data. You can revoke microphone access in macOS System Settings → Privacy & Security → Microphone.

### Children, third parties, and data sharing

The app does not transmit any information to third parties, provide advertising identifiers, or perform cross-app tracking.

### Updates

This policy may be updated to accurately reflect future versions. A change introducing external processing or data collection would require updating both this document and the app's disclosures before release.
